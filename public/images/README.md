# TB Accounting Services: website photos

Every photo here is an AI-generated illustration made with Higgsfield (GPT Image 2.6, quality high, 2K, 16:9) for revision 3, November 2026. None shows the owner, staff, clients or the firm's real office, and the site never presents them that way. Every alt text starts with "Illustrative photo:".

**Each photo is used on one page only.** `node tools/image-dupes.mjs public` checks this and must print OK.

Each photo has 5 files: `<name>.jpg` (1920 wide, under 400 KB), `<name>-800.jpg`, and `<name>-800.webp`, `-1280.webp`, `-1920.webp`. Pages load them through `<picture>` with `srcset`.

Every result was checked before use for hands, faces, warped objects, readable or fake text, anything on a screen, charts, a glossy or CGI look, snow, and big-city skylines. All 17 passed on the first generation.
