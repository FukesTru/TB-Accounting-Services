# TB Accounting Services — website images

AI-generated illustrative photographs for the TB Accounting Services website. They are not photos of the business owner, staff, clients, or the firm's actual office.

Generated with the Higgsfield connector, model **GPT Image 2.6** (quality: high, resolution: 2K, 16:9). Web files below were resized to a maximum width of 1920px and compressed as JPEG under ~400KB. Original 2688×1520 PNG downloads are in `raw/`.

Client logo files from the current site (https://www.tbacct.com) are in `logo/`. The form said the originals are SVG / AI / EPS in a Google Drive folder, but that folder could not be listed or downloaded on this pass (it requires Google sign-in; no Drive connector was available).
